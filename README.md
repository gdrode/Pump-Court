# Pump-Court
A push-up contest judged by software. A side-on webcam tracks your body in the browser, three referee lights call each rep, and clean reps go on a public leaderboard.

Pump-Court is a push-up contest judged by software. Stand side-on to the camera, and pose tracking runs in the browser to count only clean reps. Three referee lights show pass or fail for each rep, with the reason for any failed rep, such as “depth” or “lockout”. Scores go on a leaderboard that runs during judging, and each round ends with a report on the player’s main problems.

All video is processed live on the game laptop. Nothing is recorded or uploaded.
